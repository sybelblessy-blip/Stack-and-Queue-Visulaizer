    Learn the basic concepts of Stack and Queue.

    📚 1. What is a Stack?

    A Stack is a linear data structure that follows LIFO — Last In, First Out. The last element inserted is the first one removed.

    Example

    Think of a stack of plates. You place a new plate on top and remove the top plate first.

    Basic Operations

    • Push: Insert an element.
    • Pop: Remove the top element.
    • Peek: View the top element.
    • Is Empty: Check whether the Stack is empty.
    • Is Full: Check whether the Stack is full.

    🚶 2. What is a Queue?

    A Queue is a linear data structure that follows FIFO — First In, First Out. The first element inserted is the first one removed.

    Example

    Think of people standing in a line. The person who arrives first is served first.

    Basic Operations

    • Enqueue: Insert an element at the rear.
    • Dequeue: Remove an element from the front.
    • Front: View the first element.
    • Is Empty: Check whether the Queue is empty.
    • Is Full: Check whether the Queue is full.

    ⚡ 3. Time Complexity

    Time complexity describes how the running time of an operation grows as the input size increases.

    Operation Stack Queue
    Insert Push — O(1) Enqueue — O(1)*
    Remove Pop — O(1) Dequeue — O(1)*
    View next element Peek — O(1) Front — O(1)
    Check size O(1) O(1)

    *These complexities assume a suitable Stack or Queue implementation. A simple array-based implementation may have different costs for some operations.
